# AttoMate Web

Landing page for AttoMate, an AI Automation Agency in Indonesia.

Built with Astro 6.4 + Tailwind CSS v4. Static output, 5 pages.

## Commands

| Command          | Action                    |
| ---------------- | ------------------------- |
| `npm install`    | Install dependencies      |
| `npm run dev`    | Start dev server          |
| `npm run build`  | Build to `dist/`          |
| `npm run preview`| Preview production build  |

## Stack

- Astro 6.4.2
- Tailwind CSS 4.3.0 (via `@tailwindcss/postcss`)
- PostCSS
- Geist + Inter (Google Fonts)
- Material Symbols Outlined (icons)
